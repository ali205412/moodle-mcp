# Phase 05: Core Learning Surface & File Flows - Pattern Map

## File Classification

- `classes/local/catalog/wrapper_registry.php` - wrapper/workflow descriptors
- `classes/local/catalog/catalog_builder.php` - coverage source
- `classes/local/tool_provider.php` - discovery projection
- `tests/tool_provider_test.php` - discovery/workflow tests

## Pattern Assignments

### Harvested Read Surfaces

- Pattern: curated harvested tool exposure
- Use the existing harvested catalog and add better workflow metadata for core learner/personal reads.

### File Workflow Composition

- Pattern: thin orchestration over draft/private-file primitives
- Prefer documented multi-step flow descriptors or very small wrappers over replacing the underlying Moodle file APIs.

### Wrapper Registry Expansion

- Pattern: explicit workflow wrapper descriptors
- Add wrapper descriptors for file flows even before later broad wrapper phases.
